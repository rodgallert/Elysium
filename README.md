# Elysium

In the World of Darkness, Elysium is neutral ground — a place where vampires of rival clans and courts set their politics aside and coexist, if only for a night, under a shared roof.

This repository borrows the name for the same reason: it's neutral ground for a handful of otherwise unrelated projects. Each one lives in its own folder, named after something out of the World of Darkness, and each is free to be whatever it needs to be — its own stack, its own conventions, its own reason for existing — without having to answer to the others.

## What this is

A personal monorepo, not a product. It's where I keep the things I build to learn something, try an idea out, or show a slice of what I can do — one project per folder, each self-contained and framework-independent from the rest. No shared tooling, no shared dependencies between them; the only thing they have in common is the roof.

Think of it less as a single application and more as a running record of what I'm studying, what I've shipped, and what I'm currently curious about.
